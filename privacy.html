拾册隐私政策

让说明书好找，也让数据的去向清楚。你的扫描件默认私密，共享和连接外部 AI 都由你决定。

1. 使用 Apple 账号登录

拾册由 weicong xie 运营，用于整理、收藏和检索产品说明书。使用应用需要先通过 Apple 登录；账号用于个人书架归属、云端访问与账号管理。

我们处理 Apple 身份标识、应用账号标识、Apple 提供的可选邮箱地址和登录凭证。Apple 可能提供真实邮箱或隐藏邮箱地址，我们不索取 Apple 密码。授权码由服务端向 Apple 交换，用于撤销授权的刷新令牌经加密保存；完成关联后才保存本机登录状态。

2. 扫描和识字先在设备上完成

封面识别、纸本扫描、PDF 生成、页面 OCR、本机关键词搜索和阅读在设备上处理。本机 PDF、封面、识别文字、备注、阅读位置和收藏信息保存在应用空间，并按账号区分显示。备注与阅读位置保存在当前设备。

登录本身不会自动上传本机说明书。原始相册照片和拍摄原图只在设备上处理；你主动备份扫描件时，生成的 PDF 内的扫描页面会随该 PDF 上传。系统照片选择器仅提供你选择的项目；相机权限可在 iOS 设置中撤回。设备系统备份可能包含应用资料，取决于你的系统备份设置。

3. 私人文件备份与检索文字

主动进行私人云端备份时，我们保存你选择的 PDF、其中的扫描页面、按页 OCR 文字、产品标题、品牌、型号、语言和所属账号，用于备份、同步与检索。原始相册文件不直接上传。私人文件通过账号访问控制和有时效的下载链接提供。

下载已收藏的官方 PDF 前，界面会明确提示其文字将同步到你的私有检索库。选择下载并阅读后，设备先提取或 OCR 页面，再自动同步说明书文字、页码及校验用文件指纹，供你本人授权的 MCP 检索。此流程不上传官方 PDF 原件、不公开文字，也不包含个人备注。文字同步失败不影响本机阅读，可在详情中重试；移除对应云端收藏或删除账号会一并删除私人索引。

官方说明书的共享目录只保存产品信息和经核验的来源链接；PDF 由你的设备从官网或其验证过的 CDN 直接下载，拾册不镜像官方 PDF。其他文档的共享需要你明确提交并经过审核，不会因为私人上传而自动公开。经批准共享的文档和产品资料可被其他用户访问；请只提交有权共享的内容，并移除姓名、地址、序列号和私人笔记。公开可访问的原厂链接不等于 PDF 获准转载。

已经由其他人保存或导出的共享副本无法远程收回。我们可能处理你提交的举报、权利说明和支持请求，以纠错、处理侵权或限制违规账号。

4. 查找说明书与连接 AI

你确认品牌、型号与语言后，服务先查询共享目录；需要联网发现时，仅将这些产品信息交给 OpenRouter，再由其转交所选模型服务商及联网搜索引擎查找公开资料。当前采用 Luna 模型与 Parallel 联网搜索，具体配置发生实质变化时会更新披露。照片、PDF 文件、OCR 正文、个人备注、Apple 身份、邮箱及登录或 MCP 凭证不会发送给这条搜索服务链路。请先移除型号字段中意外识别出的个人资料。查询结果可缓存，账号标识与用量记录仅用于拾册自身的访问控制和额度管理，不随产品查询转交搜索服务。

本机阅读、搜索、OCR 和私有索引同步不调用云端 AI。你主动创建只读 MCP 令牌并交给外部 AI 服务后，该服务可以读取令牌范围内云端收藏的产品资料、私人索引或已备份扫描件的页面文字、页码与来源。官方 PDF 原件虽然不上传，其已同步文字仍可供本人授权的 MCP 读取；未同步也未备份的本机内容不因此开放。外部服务收到资料后的保存和使用受其自身政策约束；请先了解该服务，并在不再需要时撤销令牌。

5. 服务提供方、日志与安全

Supabase 提供认证、数据库和文件存储；Apple 提供登录及设备能力；按需联网发现通过 OpenRouter、所选模型服务商和联网搜索引擎处理，当前搜索引擎为 Parallel。服务商可能在其运营所需地区处理请求，其数据保留、训练及其他处理条款可能不同。相关条款可查看 Supabase 隐私政策、Apple 隐私政策、OpenRouter 隐私政策、模型服务商与数据政策和Parallel 隐私政策。更换实际处理数据的服务商前，我们会核对数据范围并相应更新披露。

服务可能产生必要的请求时间、状态、账号额度、错误及安全记录，用于运行、防滥用和故障排查。我们采用加密传输、账号权限隔离与受限管理访问。拾册不出售个人数据，不投放广告，也不进行跨应用广告追踪。此支持网站没有追踪脚本、Cookie 分析或外部媒体；GitHub Pages 与 GitHub Issues 仍会按其服务政策处理必要的访问和提交信息。

6. 保存、导出与删除

本机资料保留至你删除对应内容或清理应用；退出登录关闭应用访问，但不自动删除该账号的本机文件。保持本机登录状态时，可离线阅读已下载的文档。卸载可能清除仅存本机的资料，重要 PDF 请先导出备份。

云端资料保留至你删除内容、删除账号，或因违规、侵权需要移除。官方说明书的私人索引会随移除对应云端收藏或删除账号一并清理。可在「我的」发起账号删除：先撤销 Apple 授权，再清理关联云端内容、收藏与 AI 连接，成功后清理当前设备该账号的书架。删除失败会提示重试，不会把失败显示为完成。应用外导出的文件由你自行管理。

服务商备份按实际启用的服务配置与备份周期轮转、到期清除，不承诺未经配置核实的固定天数。清除前的备份仅用于必要恢复和安全，不作为继续提供账号服务的活跃数据。为处理删除后的延迟上传、防止滥用或履行法定义务，可能在必要范围内保留删除状态与安全记录；不用于恢复已删除账号。如依法需要保留其他资料，会说明保留依据和范围。

7. 你的选择与政策变更

你可以撤回相机权限、停止上传和联网发现、导出 PDF、移除收藏、撤销 MCP 令牌，或删除账号。已经发送至外部 AI 的内容需要按该服务的流程处理。我们不要求提供出生日期，不面向儿童提供广告或社交功能。

本政策适用于拾册正式提供的服务；正在准备、尚未开放的功能不会仅因写入政策而开始收集数据。处理目的、服务提供方或共享方式有实质变化时，会更新本页，并在需要时重新征求同意。
