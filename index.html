这里是拾册的使用与支持页面。我们正在准备首次发布，下面的说明适用于正式开放的功能。

服务准备中
01

先打开自己的书架

通过 Apple 登录拾册。首次登录需要网络，并完成账号授权关联；取消或失败时，请重新尝试。每个账号只显示属于自己的本机收藏。

02

纸本拍下，PDF 导入

在书架添加说明书，选择扫描纸张或导入 PDF。每份最多 30 MB、150 页。确认页数完整、图像清晰，再决定如何处理纸本。

03

查型号，也查关键词

拍摄封面后核对品牌、完整型号和语言，再查找线上资料。已保存的说明书可搜索关键词并回到对应页面；文字识别不完整时，请查看原始页面。

04

留好自己的副本

完成登录并保留本机登录状态后，已下载文件可离线阅读。重要资料请导出到「文件」备份；卸载应用可能清除仅存本机的内容。

遇到问题，给我们留一条消息。

在 GitHub Issues 提交错误、功能建议、资料纠错或版权问题。描述相关功能、产品型号、公开来源链接与问题页码，就能帮助我们定位。

前往支持与反馈  ↗

GitHub Issue 公开可见，提交需要 GitHub 账号。请勿上传私人说明书、姓名地址、序列号、登录截图、密码或任何令牌。版权投诉先提供公开来源标题、链接及简要权利说明；如需非公开证据，请先在 Issue 中请求合适的私密联系渠道，不要公开附件。

常见问题

扫描或搜索不准确，怎么办？

把纸张放平，避免反光和阴影。检查型号里的 O / 0、I / 1，再缩短关键词重试。OCR 在设备上处理，无法保证识别所有字体、折页和低清晰度页面。

为什么联网查找暂时不可用？

线上发现需要网络、已配置的服务及剩余查询额度。没有可靠结果时，可以先扫描纸本或导入 PDF。找到的资料仍需核对具体型号、语言与版本。

上传后，别人能看到我的说明书吗？

私人云端文件默认只属于你的账号。提交共享需要明确确认并经过审核，上传备份不会自动公开。只有拥有相应权利的文档才能提供共享下载，其他资料可以保留原厂来源链接。

下载官方 PDF 后，会同步什么？

下载前会明确提示：设备提取或 OCR 的说明书文字和页码将自动同步到你的私有检索库，供你本人授权的 MCP 使用。不上传官方 PDF 原件、不公开，也不包含备注。同步失败不影响本机阅读，可在详情重试；移除对应云端收藏或删除账号会一并清理私人索引。扫描件的私人文件备份仍需你主动操作，原照片只在设备处理，共享始终需要明确申请并审核。

连接 AI 会发送哪些内容？

联网发现只向 OpenRouter 提供你确认的品牌、型号和语言，并由其转交所选模型服务商和联网搜索引擎；当前采用 Luna 模型与 Parallel 搜索。照片、PDF、OCR 正文、备注及账号凭证不会发送给这条搜索服务链路。你主动创建 MCP 令牌并交给外部 AI 后，该服务可只读检索令牌所授权收藏的产品信息、已同步私人索引或已备份扫描件的文字和页码。官方 PDF 未上传原件，也可能已经同步文字；未同步且未备份的本机内容不因此开放。请只把令牌交给信任的服务，并在「我的」撤销不再需要的连接。

退出登录和删除账号有什么区别？

退出会关闭应用访问，保留该账号的本机副本；重新通过同一 Apple 账号登录可继续查看。删除账号会先撤销 Apple 授权，再删除关联云端内容、收藏与 AI 连接，成功后清理当前设备对应的本机书架。导出到应用外的文件由你自行管理。请先备份，失败提示不表示已完成删除。

隐私和数据处理方式，请查看拾册隐私政策。产品操作与安全事项请以匹配型号的原厂资料为准。
